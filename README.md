## 使用心得

- **Star ≠ 学会**：星标只是入口，认真看完一个就写点笔记或动手复现，才是自己的东西。
- **英文 README 是很好的阅读材料**：每天精读一小段，习惯直接读一手文档。
- **善用 AI 助手**：读源码时边读边问，理解效率翻倍。
